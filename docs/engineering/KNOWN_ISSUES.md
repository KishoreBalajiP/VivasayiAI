# Known issues

**Status (2026-10-17).** Open issues in the backend (`develop` after `6dbe6b8`, with an uncommitted working tree) and the frontend (`develop` after `56f26eb`, with an uncommitted working tree). Each entry was checked against the code or a saved result; the source is named. Items marked **owner decision** need a product, legal or operational decision rather than a code change.

Severity: **High** can stall a claim, cause a wrong or adverse outcome, or block a release. **Medium** is a functional gap with a workaround. **Low** is cosmetic, documentation or tooling.
